문제지 사진을 PDF로 저장하는 방법

스마트폰 사진 그대로 인쇄하면 배경이 어둡고 글자가 흐려질 수 있습니다. 먼저 보정을 적용한 뒤 PDF로 저장하면 A4 안에 맞춰 다시 풀기 좋은 자료를 만들 수 있습니다.

PDF 저장 순서

  1. 문제만 첫 화면에서 사진 올리기를 선택합니다.
  2. 자동으로 깨끗하게 만들기를 눌러 기본 보정을 적용합니다.
  3. 원본과 결과를 비교하며 배경 제거, 대비, 밝기를 조절합니다.
  4. 결과가 읽기 좋으면 PDF로 저장을 누릅니다.
  5. 다운로드된 PDF를 열어 A4 인쇄 미리보기에서 여백을 확인합니다.

PNG와 PDF 중 무엇을 고를까?

PNG는 노트 앱에 붙이거나 메신저로 공유할 때 편합니다. PDF는 인쇄하거나 파일로 보관할 때 더 안정적입니다. 문제 한 장을 깔끔하게 다시 풀 목적이면 PDF가 좋고, 문제 일부만 잘라서 쓰려면 PNG가 더 편합니다.

여러 장 정리할 때

현재 문제만은 페이지별 PNG/PDF 저장을 우선 제공합니다. 여러 페이지를 한 파일로 묶는 기능은 추후 개선 대상입니다. 지금은 페이지마다 파일명을 과목, 날짜, 단원 기준으로 정리하면 오답 복습 때 찾기 쉽습니다.
