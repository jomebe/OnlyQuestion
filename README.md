# 문제만

사진으로 찍은 시험지에서 종이색, 그림자, 형광펜, 색펜 흔적을 줄이고 문제 텍스트만 깔끔하게 남기는 브라우저 기반 MVP입니다.

## 배포

- GitHub Pages: https://jomebe.github.io/OnlyQuestion/
- 현재 정책: 베타 기간 무료, 정식 출시 후 유료 전환 예정

## 실행

```powershell
npm install
npm run dev
```

## 이용권 테스트 코드

- `CLEAN10`: 10장 추가
- `PRO1900`: 월 무제한 모드

## 수동 검증

1. 시험지 사진을 업로드합니다.
2. 원본과 결과 미리보기가 모두 보이는지 확인합니다.
3. 배경 제거, 대비, 밝기, 색펜/형광펜 제거 슬라이더를 움직여 결과가 바뀌는지 확인합니다.
4. 흑백 변환을 켜고 껐을 때 결과가 바뀌는지 확인합니다.
5. PNG 저장과 PDF 저장을 각각 눌러 파일이 다운로드되는지 확인합니다.
6. 베타 무료 문구와 정식 출시 예정 가격 모달이 보이는지 확인합니다.
7. 이용권 코드를 입력하면 localStorage 사용량이 바뀌는지 확인합니다.
