# 문제만

사진으로 찍은 시험지에서 종이색, 그림자, 형광펜, 색펜과 손글씨를 줄이고 문제 텍스트만 깔끔하게 남기는 브라우저 기반 서비스입니다. 손글씨 제거 모델은 PyTorch로 학습하고 ONNX WebGPU로 브라우저에서 실행합니다.

## 배포

- GitHub Pages: https://jomebe.github.io/OnlyQuestion/
- 현재 정책: 베타 기간 무료, 정식 출시 후 유료 전환 예정

## 실행

```powershell
npm install
npm run dev
```

## 이용권 테스트 코드

- `CLEAN10`: 10장 추가
- `PRO1900`: 월 무제한 모드

## 수동 검증

1. 시험지 사진을 업로드합니다.
2. 원본과 결과 미리보기가 모두 보이는지 확인합니다.
3. 배경 제거, 대비, 밝기, 색펜/형광펜 제거 슬라이더를 움직여 결과가 바뀌는지 확인합니다.
4. `AI 손글씨 제거`를 눌러 WebGPU 처리 결과가 표시되는지 확인합니다.
5. 흑백 변환을 켜고 껐을 때 결과가 바뀌는지 확인합니다.
6. PNG 저장과 PDF 저장을 각각 눌러 파일이 다운로드되는지 확인합니다.
